A modern, Gutenberg-first WordPress theme for Young Entrepreneurs Albania.

== Description ==

YEA Theme is a professional WordPress theme designed specifically for Young Entrepreneurs Albania (YEA). It combines a modern, youthful aesthetic with institutional credibility - perfect for nonprofit organizations, educational institutions, and youth-focused initiatives.

**Key Features:**

* Gutenberg-First Editing - Edit homepage and page content directly in Gutenberg
* Editable Media - Hero, programs, and community photos use native Gutenberg Image/Cover blocks
* Custom Logo Support - Upload your own logo
* Multiple Menu Locations - Primary, Footer, and Donors menus
* Hero Section - Editable hero built from native Gutenberg blocks
* Impact Statistics - Animated counters for showcasing achievements
* Programs Showcase - Display your programs with editable media blocks
* Community Gallery - Photo mosaic section
* Partners Section - Editable logo wall and partner areas
* Transparency Reports - Document download section
* Call-to-Action Band - Editable CTA buttons and layouts
* Responsive Design - Works on all devices
* Smooth Animations - Scroll reveals, counter animations, hover effects
* Form Plugin Ready - Styled support for WPForms and Contact Form 7
* Premium Components - YEA accordion, FAQ, testimonials, team, donor stats, logo wall, form sections, and CTA banners
* SEO Friendly - Clean code structure
* Translation Ready - WPML compatible
* Gutenberg Compatible - Full block editor support

**Editing Options:**

* Site Editor support for header, footer, navigation, and templates
* Editable homepage sections built from core Gutenberg blocks and patterns
* Native Columns blocks for split hero and flexible page layouts
* Custom page templates for standard pages, blog landing, and contact
* Theme-wide colors, spacing, and typography managed through `theme.json`

== Installation ==

1. Download the theme zip file
2. Go to Appearance > Themes in your WordPress admin
3. Click "Add New" and then "Upload Theme"
4. Choose the zip file and click "Install Now"
5. Click "Activate" to activate the theme

== Setup ==

**1. Add Your Logo:**
- Go to Appearance > Editor
- Upload or replace your site logo

**2. Set Up Menus:**
- Go to Appearance > Editor > Navigation
- Edit the header navigation and assign the links you want

**3. Customize Content:**
- Create or edit your static front page in Gutenberg
- Insert the `Homepage Full Layout` pattern
- Edit the hero, images, columns, statistics, sections, and buttons directly in the block editor

**4. Create Pages:**
- Create pages like About, Programs, Contact, or Donors
- Choose `Page Builder`, `Blog Landing`, or `Contact Page` from the template selector when needed

**5. Add Blog Posts:**
- Create posts normally in WordPress
- Use the blog template or posts page to display them with the theme styling

**6. Set Up Widgets (Optional):**
- Go to Appearance > Widgets
- Add widgets to footer areas if desired

== Frequently Asked Questions ==

= How do I change the primary color? =
Use Appearance > Editor > Styles to adjust the site colors in the block theme interface.

= How do I add my own images? =
Replace the Image or Cover blocks directly in Gutenberg. The hero, programs, community sections, logos, and team cards all use native editable media blocks.

= Can I add more than 3 programs? =
The theme is designed with 3 program cards for optimal visual balance. To add more, you would need to customize the theme code or use a page builder plugin.

= How do I add partner logos? =
The partners section currently displays text labels. To add actual logos, you can modify the theme code or use a plugin like "Logo Showcase".

= Is the theme translation-ready? =
Yes! The theme is fully internationalized and ready for translation. All text strings use WordPress translation functions.

= Does it work with page builders? =
Yes, the theme is compatible with popular page builders like Elementor, Beaver Builder, and the native WordPress Block Editor (Gutenberg).
